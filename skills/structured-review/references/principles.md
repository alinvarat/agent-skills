# Review principles
- prove-it-works: claims need a run or inspected output.
- fix-root-causes: no stacked symptom fixes.
- subtract-before-you-add: delete or reuse before adding.
- boundary-discipline: validate at entry points, clean error propagation.
- redesign-from-first-principles: do not bolt changes onto a design that no longer fits.
- Owner rules: `<library-root>/shared-agent-rules.md` and `memory/preferences/user.md` (keep requested features, never discount prices alone, stay in scope).
