# Unslop
1. Read the text and the intended audience and tone. Keep facts, numbers, names, prices and quoted wording unchanged.
2. Mark patterns from [patterns](references/patterns.md). Thai text also uses the Thai section there.
3. Rewrite to remove them without changing meaning. Then add voice: concrete detail over generalities, varied sentence length, an opinion where the author has one, "I/ผม/เรา" where natural. Do not add facts.
4. Self-audit once: "what still reads as machine-written?" and fix it.
5. Return the edited text. For a long text also list the main changes in at most 3 lines. Do not overwrite the source file unless asked; back up first when asked to edit in place.
